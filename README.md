### 📊 [Yelp Data Engineering Pipeline](https://github.com/SebastianGronbech/dat535-project)

A large-scale ETL and sentiment-analysis pipeline built on the **Yelp Open Dataset** using a Medallion Architecture.

**Tech:** Python · Apache Spark · PySpark · MLlib · Parquet · Jupyter

* Designed a **Bronze → Silver → Gold** data pipeline
* Processed and transformed large-scale Yelp review and business data
* Implemented resilient JSON parsing, validation and deduplication using Spark RDDs
* Stored processed datasets using partitioned Parquet
* Built an NLP pipeline using **TF-IDF and Logistic Regression**
* Generated business-level sentiment and review aggregates
